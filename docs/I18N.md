# OwOGG 다국어(i18n) 아키텍처 (I18N)

이 문서는 OwOGG의 4개 언어 지원 아키텍처, 타입-안전 내부 사전 시스템, 로케일 해석 순서 및 저장 정책을 정의합니다.

---

## 1. 🌐 지원 로케일 목록

| 로케일 코드 | 언어            | 상태         |
| :---------- | :-------------- | :----------- |
| `ko-KR`     | 한국어 (기본값) | 전체 적용    |
| `en-US`     | English         | 주요 UI 적용 |
| `ja-JP`     | 日本語          | 주요 UI 적용 |
| `zh-CN`     | 简体中文        | 주요 UI 적용 |

- 단일 소스: `packages/core/src/domain/i18nPolicy.ts` (`SUPPORTED_LOCALES`)

---

## 2. 📖 타입-안전 내부 사전 아키텍처

외부 라이브러리(i18next 등) 의존성 없이 가볍고 빠른 TypeScript 사전 구조를 채택했습니다:

- `apps/web/app/features/i18n/dictionary.ts`의 `Dictionary` 인터페이스가 모든 번역 키 구조를 강제합니다.
- `useI18n()` 훅을 통해 컴포넌트에서 `dict.nav.login` 형태로 오탈자 없이 자동완성 접근합니다.

---

## 3. 🔍 로케일 해석 순서 (Resolution Order)

1. **인증된 사용자의 서버 저장 로케일** (`user.locale`, `GET /api/auth/me`)
2. **로컬 스토리지 선호도** (`localStorage.getItem("owogg_locale")`)
3. **브라우저 언어 매칭** (`navigator.languages` ➔ `matchBrowserLocale`)
4. **기본값 fallback** (`ko-KR`)

> 로그인한 사용자가 서버에 저장된 로케일이 없을 경우(`null`), 현재 브라우저 선호도를 1회 채택하여 서버에 동기화합니다.

---

## 4. 💾 저장 정책

- **인증 사용자**: `users.locale` (D1 컬럼, `POST /api/profile/locale` 호출 시 즉시 갱신, **쿨다운 없음**).
- **게스트**: 브라우저 `localStorage`에만 저장.

번역 커버리지(어느 화면까지 4개 언어가 실제 연결되어 있는지)의 최신 상태는 이 문서가 아니라
[`docs/i18n-content/STATUS.md`](i18n-content/STATUS.md)에서 관리합니다 — 화면이 늘어날 때마다
이 아키텍처 문서를 고치지 않아도 되도록 분리되어 있습니다.
